# E-Commerce Shipping Delay Prediction and Analytics

An interactive web application demonstrating machine learning prediction and data analytics for e-commerce shipment delays.

## Features
- **Predict Shipment**: Real-time delay prediction using Decision Tree and Random Forest models with What-If scenario analysis.
- **Dataset Insights**: Overview statistics, delivery status distribution, and key factor visualizations.
- **Model Comparison**: Side-by-side performance metrics (Accuracy, Precision, Recall, F1), confusion matrices, and feature importance rankings.
- **About Project**: Project workflow, data preprocessing pipeline, and methodology.
